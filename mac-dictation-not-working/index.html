Mac dictation not working? Here’s how to fix it.

Most dictation failures on a Mac come down to five things: the shortcut, the microphone, the language, a restriction, or the app you are typing into. Work through the checks below in order — each takes under a minute. The steps use the names in macOS Sonoma and Sequoia; older versions keep the same settings under System Preferences.

1. Check that dictation is actually on

  1. Open System Settings → Keyboard.
  2. Scroll to Dictation and make sure it is switched on.
  3. If it was already on, switch it off, wait a few seconds, and switch it on again. This clears a stuck dictation process more often than you would expect.

If the switch is greyed out, skip to step 6 — something is restricting it.

2. Fix the dictation shortcut

When nothing happens at all, the shortcut is the usual suspect. It often changes after a macOS update or when you plug in a different keyboard.

  1. In System Settings → Keyboard → Dictation, open the Shortcut menu and choose something easy to trigger, such as pressing Control twice.
  2. If you use the Globe (fn) key, check Press 🌐 key to at the top of the Keyboard settings. If it is set to change the input source or show emoji, the double-press for dictation may not fire.
  3. On keyboards with a microphone key (F5 on recent Mac keyboards): if Use F1, F2, etc. keys as standard function keys is on, you have to hold fn while pressing it.
  4. Third-party keyboard tools (Karabiner-Elements, BetterTouchTool, gaming-keyboard software) can swallow the key. Quit them briefly to test.

3. Pick the right microphone

Dictation does not always use the microphone you expect. With headphones, a USB mic or an external display connected, it may be listening to the wrong one — the dictation indicator appears, but no words come out.

  1. In System Settings → Keyboard → Dictation, set Microphone source to the mic you are using instead of Automatic.
  2. In System Settings → Sound → Input, select the same mic and speak: the input level meter should move. If it doesn’t, the problem is the microphone, not dictation.
  3. Bluetooth headsets switch to a lower-quality mode when their mic is in use, which hurts accuracy. The Mac’s built-in mic is often better than an AirPods mic for dictation.

4. Check the dictation language

If dictation types the wrong words, or nothing, it may be listening in the wrong language — or the language may still be downloading for on-device use.

  1. In System Settings → Keyboard → Dictation, open Languages and make sure the language you speak is there.
  2. With several languages added, the active one is shown next to the microphone while you dictate; click it to switch.
  3. Right after adding a language, give your Mac a few minutes on Wi-Fi to download it.

More detail in how to change the dictation language on a Mac.

5. Google Docs, Chrome and other apps

If dictation works in Notes but not in one particular app, the app is the problem, not your Mac.

  1. Google Docs: Docs draws its own editor, and system dictation into it can drop words or stop. Docs has its own Tools → Voice typing, which works in Chrome.
  2. Chrome and other browsers: web-based voice typing needs the browser to have microphone access — check System Settings → Privacy & Security → Microphone and the site’s permission in the address bar.
  3. Terminal, remote desktops and some games: these handle keyboard input in their own way and may not accept dictated text reliably. Dictate into a text editor and paste.

6. Screen Time and work Macs

A greyed-out dictation switch usually means something is blocking it.

  1. Open System Settings → Screen Time → Content & Privacy and check that Siri & Dictation is allowed in the app and feature restrictions.
  2. On a company-managed Mac, a configuration profile can disable dictation. Check System Settings → General → Device Management; if a profile is there, ask your IT team.

7. Still broken? Restart and update

Restart the Mac, then install any pending update in System Settings → General → Software Update. Dictation bugs do get fixed in point releases, and a restart clears the speech services that sometimes hang after sleep.

Questions

Why did dictation suddenly stop working on my Mac?
The most common causes are a changed keyboard shortcut (often after a macOS update or a new keyboard), the wrong microphone selected for dictation, a language that is still downloading, or a Screen Time or company profile that turns dictation off. Turning dictation off and on again in System Settings → Keyboard fixes many one-off failures.
How do I fix the dictation shortcut on a Mac?
Open System Settings → Keyboard, find Dictation, and pick a shortcut you can press reliably, such as pressing Control twice. If you use the Globe (fn) key, check that “Press 🌐 key to” is not set to something else, and if your F-keys act as standard function keys, the microphone key may need fn held down.
Why does Mac dictation not work with my external microphone?
Dictation has its own microphone setting. In System Settings → Keyboard → Dictation, set Microphone source to your external mic instead of Automatic, and check its input level in System Settings → Sound → Input.
Does Mac dictation work in Google Docs?
System dictation types into most text fields, but Google Docs draws its own editor and dictation into it can be unreliable. Google Docs also has its own Voice typing (Tools → Voice typing), which works in Chrome and needs Chrome to have microphone access.
Why does Mac dictation keep stopping?
Apple's dictation ends a session on its own after a pause in speech, and it can stop when you switch windows or click elsewhere. A hold-to-talk dictation app records for exactly as long as you hold the key, so a pause never ends it.
